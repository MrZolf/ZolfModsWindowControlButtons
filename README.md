# Zolf Mods Window Control Buttons

A CSS-only Sine mod for Zen Browser. It customizes the spacing and icon rendering of the window control buttons and lets you choose their hover background colors.

## Features

- Custom spacing around the window control buttons
- Shared icon color/rendering rules for window controls and the Reload icon
- Removes hover filters that can make icons look thinner or softer
- Configurable hover colors:
  - **None** - keeps the browser's normal hover backgrounds
  - **Close only** - applies the red hover background to Close
  - **All** - applies yellow to Minimize, green to Maximize/Restore and red to Close
- Icons become very light gray over the colored hover backgrounds
- No JavaScript or external dependencies

## Installation

1. Install [Sine](https://github.com/CosmoCreeper/Sine).
2. Open Zen Browser settings and go to **Sine Mods**.
3. Add this repository:
   `https://github.com/MrZolf/ZolfModsWindowControlButtons`
4. Install or enable **Zolf Mods Window Control Buttons**.
5. Open the mod's preferences and select **Colored buttons on hover**.

## Compatibility

Designed for Zen Browser's titlebar window-control elements and Firefox chrome CSS. Selectors may need adjustment if Zen changes those elements in a future release.
