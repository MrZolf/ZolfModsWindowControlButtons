# Zolf Mods Window Control Buttons

A lightweight CSS-only Sine mod for Zen Browser. It customizes the spacing, shadows and hover appearance of the window control buttons.

## Features

- Custom spacing around the window control buttons
- Neutral button icon color with subtle drop shadows
- Yellow hover state for Minimize
- Green hover state for Maximize / Restore
- Red hover state for Close
- No JavaScript and no external dependencies

## Installation

1. Install [Sine](https://github.com/CosmoCreeper/Sine).
2. Open Zen Browser settings and go to **Sine Mods**.
3. Add this repository as a custom mod:
   `https://github.com/MrZolf/ZolfModsWindowControlButtons`
4. Install or enable **Zolf Mods Window Control Buttons**.
5. Restart Zen if the styles do not apply immediately.

## Compatibility

Designed for Zen Browser's current titlebar window-control elements. The mod uses Zen/Firefox chrome CSS selectors and may need adjustments if those elements change in a future browser update.
